# Color Adaptation

## Principle

The reference image can teach color organization, not necessarily color choice. Rebuild the palette around supplied brand colors when present; otherwise rebuild it around the current product's identity colors, material, and category.

## Priority

1. User-provided brand colors and mandatory identity rules when supplied.
2. Product identity colors and materials: e.g. rose-pink metal, black plastic, white bottle, transparent gel, wood grain.
3. Category color psychology: e.g. home beauty appliances can use clean warm neutrals and soft premium accents; food may need fresh appetite colors; skincare needs clean/professional softness.
4. Product-flattering palette: background, auxiliary colors, and accent colors should make the product clear, premium, and credible.
5. Reference palette logic: color ratios, contrast, module separation, accent placement, not exact hue copying.

If supplied brand colors conflict with product legibility or material truth, keep the brand color as an accent or system color rather than letting it damage product clarity.

## Anti-Copy Rule

If the reference's dominant hue does not fit the supplied brand colors or product, reject it explicitly. Example: a teal/green nutrition-supplement reference can provide strong e-commerce layout and pill-tag logic for a rose-pink hair dryer, but the palette should become warm ivory, blush pink, champagne, soft gray, deep mauve/burgundy, and dark readable text.

## Generation Prompt Requirement

Every generated prompt must include a color note:

- Do not copy the reference dominant color unless it fits the supplied brand colors and product.
- Use brand/product-adapted palette: [specific palette].
- State which reference colors are forbidden or limited.
