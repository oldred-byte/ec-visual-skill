# Visual Proof Grammar

## Core Principle: Visual Proof First

Every output must use the most direct visual proof for its core message. Do not start from a pretty composition and force the selling point into it.

Planning order:

1. What is the one core message?
2. What buyer anxiety, desire, or body/use moment does this message answer?
3. **What picture would make the viewer understand or believe it fastest — even with all copy hidden?** (Picture Solo Test)
4. Who or what should be the main subject: full product, product detail, body part, ingredient, raw material, mechanism, result state, scene, or set?
5. **Does this picture actually need the product/packaging?** If no, the product does not appear. (Product-Presence Rule)
6. Does that picture need a model, ingredient scene, macro detail, mechanism diagram, comparison, parameter layout, or lifestyle use?
7. Which reference DNA elements (light, type, density, mood) can support that proof without overriding the picture?
8. What should be excluded because it distracts from or weakens the proof?

Do not add a model, scene, badge, macro, chart, or any icon-shaped element unless it helps prove the message.

## Picture Solo Test (hard gate)

Before writing any prompt, write one sentence in this exact shape:

> **"The picture is [concrete scene in 1 line]. With all text hidden, a buyer looking at it for 2 seconds would understand [specific message]."**

Rules:

- The "concrete scene" must describe what is actually visible: subjects, arrangement, camera angle, key actions. Not abstract proof-form labels like "ingredient scene" or "macro detail."
- The "[specific message]" must be the actual selling point, not "the product is good" or "this is a quality image."
- If you cannot write this sentence, the picture is failing. Redesign the picture before continuing.
- If the sentence is true only when the headline is visible, the picture is failing. Redesign.

Examples:

- ✅ Good: "Three bowls of food arranged left-to-right — banana, blueberry, oat — shot from above on a clean cream surface. With all text hidden, a buyer understands 'three familiar flavors'."
- ❌ Bad: "A pouch of baby food centered on a soft background with three flavor labels. With all text hidden, a buyer understands... 'this is baby food'." → The labels are doing the work, not the picture. Redesign: remove packaging, show the three actual foods.
- ✅ Good: "Macro of a razor blade mesh cutting a single hair, blade steel catching a hard light. With text hidden, a buyer understands 'sharp precision blade'."
- ❌ Bad: "Razor centered hero shot with 'sharp blade' headline. With text hidden, a buyer understands... 'this is a razor'." → Headline doing the work. Redesign: show the blade, not the body.

## Product-Presence Rule

The product/packaging does NOT appear by default. Decide per screen:

| Message type | Product/packaging presence |
|---|---|
| Multi-flavor / multi-color / multi-variant | No packaging. Show the actual contents arranged. |
| Natural / simple / clean ingredients | No packaging. Show raw ingredients. |
| Micro-material / texture / feel | No packaging. Show material macro. |
| Mechanism / technology / structure | No packaging or partial crop only. Show the mechanism. |
| Sensory / taste / skin-feel result | No packaging. Show the body moment or result state. |
| Scene-fit / lifestyle / audience | Maybe small context product, or none. Show the scene first. |
| Operation / how-to-use | Medium product in use, OR hand/action with partial product. |
| Detail / craft / parameter | Partial product crop, OR the relevant component only. |
| Trust / quality basis | Medium product OR testing/inspection scene. Avoid fake certifications. |
| Hero / first-image / closing set | Full product hero. This is when packaging earns its place. |

If the planned screen does not match one of the "hero/closing" cases, ask: does the message strictly require the packaging to be visible? If no → packaging does not appear.

This rule is the single most powerful anti-template lever. Defaulting to "show the product" is the most common cause of 5-images-look-identical and detail-pages-look-like-vertical-head-images failure modes.

## Use Message-to-Picture Patterns

Before designing a picture from scratch, check `references/message-picture-patterns.md`. The most common e-commerce messages already have proven picture patterns. Match the screen's message to a pattern, then adapt to the actual product and category.

Pattern library covers: multi-flavor/variant, natural ingredients, soft/skin-feel material, micro-material, mechanism/structure, scene-fit, operation/use, sensory result, parameter/detail, trust/quality, closing set, and audience persona.

## Copy Voice: Consumer-Facing, Not Explanatory (hard rule)

All copy — headlines, sub-headlines, support copy, labels — must be written from the **consumer's perspective**: what they feel, what they get, what they stop worrying about. Never from the manufacturer's perspective explaining the product.

### The Voice Test

Read each line of copy aloud. Which voice does it sound like?

- ✅ **Consumer-facing**: A brand talking to a buyer about what they'll experience. The buyer instantly knows "what's in it for me".
- ❌ **Explanatory / spec-sheet voice**: A spec sheet explaining what the product is made of or how it's's built. The buyer learns about the product but doesn't feel addressed.
- ❌ **Client-facing / deck voice**: An internal deck justifying the product to stakeholders (the brand, the boss, an auditor). Sounds official but doesn't speak to a person.

### Anti-Patterns (do NOT write these)

- "采用XXX技术" / "应用XXX工艺" — process/tech-flex, not benefit
- "本产品具有XXX功能" — manual-style, third-person
- "符合XXX标准" / "通过XXX认证" — compliance voice (also often claim-safety risk)
- "全新升级" / "新一代" without saying what changes for the user
- "精选优质原料" — vague boast
- Spec dumps: "500mAh / 8小时 / 蓝牙5.3" without translation
- "专为XXX人群设计" — demographic label, not benefit
- "高品质 / 高性能 / 高端" — empty superlatives

### Consumer-Facing Rewrites (use as reference)

| Explanatory (avoid) | Consumer-facing (use) |
|---|---|
| 采用三层复合材料 | 用一年还像新的 |
| 不锈钢精密刀头 | 一刮就干净，不用来回反复 |
| 符合婴幼儿食品标准 | 宝宝第一口辅食，放心给 |
| 便携式设计 | 出门随手一塞 |
| 大容量电池 500mAh | 一周不充电 |
| 采用UPF50+涂层 | 大太阳下也不晒 |
| 全新升级配方 | 喝起来更顺，宝宝不挑嘴 |
| 选用优质原料 | 看得见的果肉，闻得到的果香 |
| 人体工学手柄 | 拿久了手不酸 |
| 智能温控系统 | 怎么吹都不烫头皮 |

### Rule

Every headline and support copy must pass the **"so what?" test**: after reading it, the consumer should immediately know "what's in it for me" — not "what's in the product".

If a copy line is technical or explanatory, rewrite it. If a real spec must be mentioned, translate it to its consumer meaning first; the spec can be a small supporting detail, not the headline.

### Special Cases

- **Hero / first head image**: the headline must be the strongest consumer-facing promise, not a category label. "宝宝爱吃的真果泥" beats "婴幼儿辅食果泥".
- **Detail page D01 hero**: same — consumer-facing hook, not product category.
- **Parameter screens (D07/D08)**: parameters are necessary, but the headline above them should still be consumer-facing. "续航一周不充电" over "500mAh 长续航".
- **Trust screens (D09)**: avoid compliance voice. "妈妈放心给宝宝" beats "符合GB国家标准"。If a real certification exists, mention it as supporting evidence, not as the headline.
- **Closing screens (D10)**: emotional/memory hook, not a spec recap.

## No-Icon Rule (absolute)

Never include icon-shaped elements that "express a selling point" or "decorate a feature". This includes but is not limited to:

- Checkmarks, gears, lightning bolts, shields, locks, leaves, droplets, stars
- Pictogram rows beneath a headline (e.g. "✓ safe ✓ fast ✓ clean")
- Ingredient bubbles with icon illustrations
- Feature pictogram grids
- Decorative arc systems, badge ribbons, seal shapes
-任何试图"用图标代表卖点"的形态

A screen is composed of:

1. **Main visual** (the picture that proves the message — see Picture Solo Test)
2. **Main copy** (one headline, possibly with sub-headline, written in consumer voice)
3. **Optional short support copy** (1-2 short lines max, also consumer voice)

Icons are NOT a fourth component. The user will add icons later in their own pipeline if needed; the skill does not generate icons.

If a planned screen feels like it "needs icons to be complete", that is a signal the picture is failing the Picture Solo Test. Redesign the picture instead of patching with icons.

## Screen Expression Logic

For detail pages, the mature planning unit is not "a layout" but a screen expression:

| Screen direction | Consumer-facing expression | Visual evidence | Main subject | Product exposure | Copy angle |
|---|---|---|---|---|---|
| The fixed role or selling-point area | What the buyer should feel, believe, or stop worrying about | The image moment that proves it | Product, product part, body part, ingredient, mechanism, result, scene, set | hero / medium / partial / small context / none | The shortest truthful wording for the visual |

Use this before prompt writing. If the screen direction is already fixed by the user, keep it; improve only the expression and proof.

The product image is source material, not a command to make the full product dominate every screen. A mature detail page varies the main subject according to where the benefit is actually experienced:

- If the benefit is felt on a body part, the body contact or result may be the main subject.
- If the benefit depends on a component, the component or macro detail may be the main subject.
- If the benefit is an action, the use moment may be the main subject.
- If the benefit is a mechanism, the product may become semi-transparent, cutaway, exploded, or diagrammatic.
- If the benefit is lifestyle fit, the scene relationship may be the main subject.
- If the benefit is ingredient/sensory/flavor, the ingredients or food itself may be the main subject — packaging does not appear.

Avoid defaulting to "full product + big headline". That is a fallback only when the screen's task is product recognition, set display, or closing memory.

## Selling-Point Expression Grammar

Choose proof form by message type and product category.

| Message type | Better visual proof forms |
|---|---|
| Fabric/material feel | Fiber macro, weave texture, cutaway layers, skin-contact crop, stretch/airflow/cooling visualization, touch gesture when useful |
| Coolness/breathability | Fabric macro with cool light, airflow lines, skin-contact detail, relaxed body state only if it proves comfort |
| Technology/function | Component close-up, cutaway, exploded structure, energy/signal/light path, mechanism diagram, controlled render, parameter callout |
| Clean formula / zero addition | Central zero concept, subtraction list, clean ingredient arrangement, simple raw materials, empty/clean background, parent/family reassurance when relevant |
| Food nutrition | Real ingredients, bowl/product texture, source-to-meal logic, eating scene, appetite close-up, parent/child scene only when the message is use or acceptance |
| Beauty efficacy | Face/skin state, skin texture close-up, ingredient particles, absorption path, allowed comparison, lab-like proof, premium product still life |
| Portable/storage | Hand scale, bag/pocket/desktop scale, fold/open action, travel or commute scene, before/after storage state |
| Durability/safety | Structure detail, material thickness, stress/use scenario, protective mechanism, quality inspection mood without fake certification |
| Comfort/ergonomics | Human contact point, grip/fit detail, natural use posture, relaxed expression, pressure relief or body-alignment visualization |
| Premium/gifting | Product set display, ritualized opening, material shine, controlled shadow, sparse copy, warm or premium light |
| Trust/service | Clear factual basis, process/inspection scene, warranty/service only if supplied, calm layout, no fake seals or certifications |
| Parameters/specs | Clean table, product diagram, labeled parts, scale comparison, exact facts only |

If no proof form fits the supplied facts, soften the claim or choose a visible/category-generic message instead.

## Human Presence Rule

People appear only when they help prove the message:

- Use people for real usage, fit, scale, emotion, audience identification, comfort, taste acceptance, or scene credibility.
- Avoid people when the best proof is material macro, parameter clarity, component structure, ingredient logic, product set display, or a central graphic concept.
- When people appear, product interaction must be realistic for the category. Translate reference action intent instead of copying pose.
- The person does not always need to be a full model. For many mature e-commerce screens, a face crop, ear crop, hand, neck, jawline, skin contact area, foot, fabric contact area, or other body detail is more believable than a full lifestyle scene.
- When the screen is about a bodily result or sensation, the product can be secondary or partially visible. The user's body/use moment is the proof.

## Product Exposure Decision

Assign product exposure before writing each prompt:

| Exposure | Use when | Common risk |
|---|---|---|
| Hero/full product | Recognition, first screen, closing, bundle, product identity | Repeating this on every screen creates template sameness |
| Medium product in use | Operation, carry, wearing, storage, scene proof | Product may still crowd out the actual experience |
| Partial product crop | Contact points, blade head, nozzle, earbud, button, interface, material detail | Crop must stay identifiable and accurate |
| Small context product | Result, body state, scene fit, lifestyle proof | Product may become too hidden for commerce if overused |
| Mechanism/transparent/cutaway | Technical proof, structure, airflow, power path, internal parts | Do not invent internal structure without product facts or visual reference |

The strongest visual proof may require low product exposure. Do not force the product larger if doing so weakens the screen's message.

## Icon And Label Discipline (deprecated — see No-Icon Rule above)

The previous version of this skill allowed icons when "they clarify evidence". Field use has shown that any icon tolerance produces screens filled with pictogram rows, ingredient bubbles, and feature-icon grids that the user then has to remove manually.

The current rule is absolute: **no icons ever**. See the No-Icon Rule section above.

Labels and annotations (text only, no pictograms) remain allowed only when:

- They point to a real visible part or state on the main visual.
- They are necessary to explain a mechanism or comparison that the picture alone cannot convey.
- They are short (1-4 words per label, ≤3 labels per screen).

Decorative arcs, ribbons, seal shapes, and badge systems are forbidden.

## Information Density Rhythm

Assign each output a density level before prompting:

- Light: one main message, one strong visual, minimal labels. Best for emotional memory, lifestyle, premium mood, simple benefit, or clear product recognition.
- Medium: headline, short support copy, 1-3 labels or annotations. Best for most selling points and usage scenes.
- Heavy: data, comparison, parameter table, mechanism, ingredient map, multi-part proof. Use only when the message needs evidence density.

A full set should usually mix light, medium, and heavy outputs. If every screen is heavy, the set feels tiring. If every screen is light, proof and conversion weaken.

## Visual Distance Matrix

Before writing prompts, build a distance matrix so the set does not collapse into repeated layouts.

Use columns:

| Output | Core message | Consumer expression | Proof form | Camera distance | Main subject | Product exposure | Human role | Density | DNA carried | Repetition risk |
|---|---|---|---|---|---|---|---|---|---|---|

Vary at least three of these across adjacent outputs when possible:

- Proof form: hero, scene, macro, mechanism, comparison, parameter, trust, set display.
- Camera distance: wide scene, medium use, close product, macro detail.
- Main subject: product, product+human, material, ingredients, parameter, result, set.
- Product exposure: full hero, medium, partial crop, small context, or mechanism-only.
- Human role: none, hand only, partial body, face, full lifestyle scene, supporting extras.
- Density: light, medium, heavy.
- Layout family: hero poster, split scene, modular proof, centered concept, table, macro crop, product still life.

The goal is not random variation. The goal is for each output to use the most fitting proof while the full set keeps shared visual DNA. If adjacent screens have the same main subject, same product exposure, same camera distance, and same headline-product relationship, the set is likely drifting into a template.

## Prompt Requirement

Every prompt should include:

- Picture Solo Statement (the one-line "the picture is X, with text hidden it shows Y").
- Core message.
- Consumer-facing expression: what the buyer should feel, believe, or stop worrying about.
- **Consumer-facing copy lock**: all copy in the prompt is written in the consumer's voice, not explanatory/spec-sheet voice. Pass the "so what?" test.
- Chosen proof form and why it fits.
- Main subject and product exposure level (explicit: hero / medium / partial / small / none — and "none" is a valid, common choice).
- Density level.
- Whether people are needed and what interaction is plausible.
- Visual DNA elements to carry from the reference (light, type, density, mood only — NOT scene/setting elements).
- **Explicit anti-icon line**: "no icons, no pictograms, no badge ribbons, no feature-icon rows".
- Elements to avoid because they do not prove the message or would repeat another output.
