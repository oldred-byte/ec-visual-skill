# EC Visual Skill 🛒✨

让 Codex 帮你把「产品图 + 参考图」整理成一套完整的电商视觉生产流程。

它适合用来做商品主图、详情页分屏、参考图拆解、生成提示词，以及成套图片的检查和返工。你给它产品和参考，它会像一个耐心的电商视觉导演一样，先看清楚产品，再拆参考，再安排每一张图该承担什么销售任务。

## ✨ 它能做什么

- 规划 **5 张电商主图**
- 规划 **10 屏竖版详情页**
- 分析参考图的布局、镜头、文字节奏和商业气质
- 根据产品重新适配颜色和视觉系统
- 为每张图写独立的生成 prompt
- 生成后检查产品一致性、文字可读性、风格稳定性
- 对失败图片进行 prompt 修正和重新生成
- 保存最终图片和验证记录

## 🧭 它怎么工作

1. **读取素材**  
   识别产品图、参考图、产品事实和目标用途。

2. **拆解参考图（语言，不是场景）**  
   只提取参考图的视觉语言——光感、字体态度、密度节奏、商业温度、模块节奏。**不复制参考图的具体场景元素**（特定布料、场地、纹理）。

3. **建立产品规则**  
   产品外观、颜色、材质、结构、使用方式优先保持准确。颜色以产品/品牌为准，不照搬参考图主色。

4. **统一规划 5 张主图 + 10 屏详情页**  
   主图和详情页一起规划、一起审核。每一张/每一屏都先匹配 message-to-picture pattern，再写 Picture Solo Statement（画面独行声明），最后写消费者视角的草稿文案。

5. **统一审核关卡**  
   输出**一张统一审核表**，包含 5 张主图 + 10 屏详情页的全部信息（画面独行声明、pattern、产品曝光、草稿文案）。用户审核通过后才开始生成。

6. **逐张写 prompt**  
   一张图一条 prompt，包含画面独行声明、pattern、产品曝光规则、消费者视角文案锁、反 icon 声明。

7. **生成、检查、修正**  
   检查项目包括：画面独行测试、消费者视角文案、无 icon、产品曝光匹配、场景模板化、集级多样性。

8. **隔离保存**  
   每个任务自动创建独立文件夹 `~/Desktop/YYYYMMDD-HHMM-<产品名>/`，主图、详情页、记录、验证报告都进去，杜绝混批。

## 🔒 v2 核心硬规则

这一版针对实际使用中暴露的问题做了 8 条硬规则升级：

- **Picture Solo Test（画面独行测试）**：每张图必须能盖住所有文案，画面独自传达 message。盖不住就重做画面，不许用文案补。
- **Product-Presence Rule（产品按需出现）**：包装默认不出现。多口味、天然成分、微观材质、机制、感官这些 message 都不该有包装。
- **No-Icon Rule（绝对禁 icon）**：不允许任何 icon 形态——勾选、齿轮、闪电、盾牌、成分泡、特征图标行、装饰弧线。icon 用户后面自己加。
- **Reference Is Language, Not Scene（参考是语言不是场景）**：参考图的场景元素（野餐布、草地、大理石）最多只能在 30% 的图里出现。
- **Set-Level Diversity（集级多样性）**：5 张主图至少 4 种不同主视觉；10 屏详情页至少 7 种。同构直接重做。
- **Copy Voice（消费者视角文案）**：所有文案从消费者视角写，通过 "so what?" 测试。不许出现"采用XX技术"、"本产品具有XX功能"、"符合XX标准"这种甲方口吻。
- **Task Folder Isolation（任务文件夹隔离）**：每个新任务在桌面建独立文件夹，时间戳+产品名命名，整套输出都进去。
- **Unified Approval Gate（统一审核关卡）**：主图+详情页一起出审核表，含草稿文案，审完才生成。

## 📦 默认输出

如果只需要方案，它会输出：

- 输入与参考角色分析
- 产品信息路由 + claim 安全小结
- 消费者视角地图
- 集级视觉 DNA + 配色系统
- **统一审核表**（5 主图 + 10 详情页，含草稿文案）
- 15 条生成 prompt

如果需要直接出图，它会继续完成：

- 在桌面创建隔离任务文件夹
- 逐张调用图片生成
- 逐张检查（含画面独行、消费者文案、无 icon、产品曝光、场景模板）
- 对不合格图片返工
- 保存独立图片文件到任务文件夹
- 生成验证说明

## ⚠️ 使用边界

这个 skill 会尽量保护商业视觉的准确性和安全性：

- 不编造价格、认证、检测结果、医疗效果
- 不复制参考图的品牌、原文案、人物和具体承诺
- 不为了追参考风格牺牲产品准确性
- 不把 contact sheet 当成最终交付图
- 不用本地贴字或拼图修补最终商业图
- 不复制参考图的具体场景元素（野餐布、大理石等）超过全集 30%
- 不在画面里放任何 icon 形态
- 不写"采用XX技术"、"本产品具有XX功能"这种解释型文案
- 不在没审核的情况下直接生成图

## 🚀 安装方式

复制到 Codex skills 目录：

```bash
cp -R ec-visual ~/.agents/skills/ec-visual
```

如果你是直接 clone 这个仓库，也可以用软链接：

```bash
ln -s "$(pwd)" ~/.agents/skills/ec-visual
```

然后重启 Codex，或按你的环境重新加载 skills。
